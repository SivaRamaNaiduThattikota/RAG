01 · CONCEPT FIRST

What is the difference?

A discriminative model learns to decide an output from an observed input. A generative model learns a model of the data—or of data conditioned on something—so it can describe how examples arise and often produce new examples.

DISCRIMINATIVE QUESTION

Given this email, is it spam or not spam?

GENERATIVE QUESTION

What do spam and non-spam emails tend to look like, and can we produce an example?

Think of discrimination as learning a decision boundary. Think of generation as learning enough of the data-producing pattern to assign probabilities or create samples.

First memory: discriminative modelling predicts which outcome fits this input; generative modelling represents how data and outcomes could be produced.
02 · WHY IT EXISTS

Why do we need both objectives?

Many applications only need a decision: approve or reject, spam or legitimate, route to HR or Finance, relevant or irrelevant. Directly learning that decision can be efficient because the model does not spend capacity representing every detail of the input.

Other applications need to create, complete, simulate, reconstruct, or explain data. They need a model that captures the structure of possible examples rather than only a boundary between labels.

The practical trade-off

If the only goal is classification and enough labelled data exists, a discriminative model often gives a direct path to strong predictive performance. A generative model may use more assumptions, but it can support sampling, missing-data reasoning, density estimation, semi-supervised learning, and other tasks beyond a single label.

Architecture principle: choose the objective from the job. Do not use a generator merely because the product contains Generative AI.
03 · CONCRETE EXAMPLE

One employee question, several model jobs

Continuity from Concept 01: we intentionally reuse the leave assistant as a controlled example. Concept 01 separated retrieval, lookup, calculation, and generation; this lesson adds the new discriminative routing and relevance objectives.

The employee asks: “What is my remaining leave balance, and summarize the relevant carry-forward policy?” Before answering, the system may need to decide what kind of request this is.

DISCRIMINATIVE STEP

Classify the request as requiring both a structured balance lookup and policy retrieval.

AUTHORITATIVE STEPS

Query Oracle for the exact balance and retrieve the applicable policy passage.

GENERATIVE STEP

Produce a clear answer using only the verified balance and retrieved policy.

The classifier does not write the final explanation. The generator should not decide the authoritative balance. A production system coordinates different components because their objectives are different.

A simpler image example

A discriminative cat detector receives an image and predicts “cat” or “not cat.” A generative image model receives a condition such as “a cat sleeping beside a laptop” and produces an image. Both may use neural networks, but they are optimized for different outputs.

04 · TECHNICAL MECHANISM

What does each model learn?

Let x be the observed input and y be a label or target. For an email example, x is the email and y is spam or not spam.

DISCRIMINATIVE

Learn p(y|x) or a direct function f(x) → y.

GENERATIVE

Learn p(x,y), often through p(x|y)p(y), or learn p(x|c) for a condition c.

Read the notation in words

  • p(y|x): probability of a label after observing the input.
  • p(x|y): probability of observing this kind of input for a chosen label.
  • p(y): prior probability of the label before observing the input.
  • p(x,y): joint probability of seeing the input and label together.

A classical generative classifier can learn p(x|y) and p(y), then use Bayes’ rule to compute p(y|x). So “generative” and “can classify” are not opposites: a generative model can support classification because its joint distribution contains enough information.

Key distinction: classify by directly learning the destination, or model how examples arise and derive the destination.
05 · ARCHITECTURE / FLOW

Follow the two modelling paths

DISCRIMINATIVE TRAINING

Labelled examples → learn boundary → predict label for new input

GENERATIVE TRAINING

Examples and conditions → learn data distribution → score or produce examples

User question → Intent / route classifier → Oracle + retrieval tools → Evidence validation → Generative model → Grounded answer

In this RAG flow, discrimination appears in routing, relevance classification, policy selection, safety checks, and answer verification. Generation appears where the system rewrites, summarizes, explains, or produces the final response.

06 · IMPORTANT DISTINCTIONS

Terms that sound similar but are not identical

Classifier versus discriminator

A classifier predicts a class for an input. A discriminator is a component trained to distinguish categories such as real versus generated. In a GAN, the discriminator guides the generator during training; the whole GAN is still a generative system.

Generative model versus Generative AI product

A generative model is a statistical or computational model. A Generative AI product is a larger system that may include classifiers, retrievers, databases, guardrails, tools, and one or more generative models.

Conditional generation versus classification

Both use an input. Classification maps the input to a restricted decision such as one label. Conditional generation produces a richer object—text, image, audio, or code—conditioned on the input.

Question Discriminative Generative
Primary target Label, score, boundary, ranking Distribution, likelihood, sample, sequence
Typical probability p(y|x) p(x,y) or p(x|c)
Example Is this query about leave? Explain the leave result.
07 · COMMON MISTAKES

What beginners often misunderstand

“Generative models cannot classify.”

A joint model can derive class probabilities with Bayes’ rule. The distinction is what was modelled, not whether a label can be produced.

“Every neural network is generative.”

No. Neural networks can be trained with discriminative, generative, self-supervised, contrastive, or combined objectives.

“A discriminator makes the whole system discriminative.”

A GAN uses a discriminator as a training signal for a generator. Judge the complete objective and output.

“LLMs should make routing decisions freely.”

They can classify, but high-risk routing may require constrained outputs, calibrated classifiers, rules, and tests.

“Generation means factual knowledge.”

A model may generate plausible data without access to the authoritative current fact.

“Discriminative always means better.”

It may win for a fixed prediction task, but it does not automatically provide sampling, reconstruction, or rich generation.

08 · YOUR PROJECT MAPPING

How both objectives appear in Oracle RAG

QUERY ROUTING · DISCRIMINATIVE Which path is required?

Predict policy retrieval, Oracle lookup, both, or unsupported request.

RELEVANCE · DISCRIMINATIVE Is this passage useful?

A reranker or relevance grader scores candidate evidence.

ORACLE · DETERMINISTIC What is the exact value?

Validated SQL returns the authoritative employee record.

ANSWER · GENERATIVE How should evidence be explained?

The LLM produces a response grounded in approved context.

Metadata and Text-to-SQL

Metadata filters such as region, leave type, employee class, effective date, and access scope are deterministic constraints. A model may classify or extract those attributes from the question, but the database applies the actual filter. Text-to-SQL generates a candidate query; validation and Oracle execution determine whether it is safe and what exact data is returned.

Question → Discriminative route → Metadata constraints → Validated SQL + retrieval → Generative synthesis → Verification
Do not force a binary choice on the whole product. A production RAG application is a composed system containing discriminative, generative, retrieval, database, and rule-based components.

04
INTUITION

Boundary learner versus data storyteller

DISCRIMINATIVE

The exam marker

Looks at an answer and decides which category or score applies. It need not learn how to write a realistic answer.

GENERATIVE

The example writer

Learns structure needed to produce or score possible examples, optionally under a condition.

Analogy boundaryReal generative models do not necessarily understand a causal story of the world; they learn a mathematical data distribution or generation procedure.
05
PRECISION

Formal definitions

A discriminative model estimates pθ(y|x) or learns a decision function fθ(x). A generative model estimates a joint distribution pθ(x,y), a marginal pθ(x), a class-conditional model pθ(x|y), or a conditional data model pθ(x|c).

Operational testAsk what probability or mapping is optimized and what outputs the trained model can produce—not merely what neural architecture is used.
06
MECHANISM

Two training routes

DIRECT CONDITIONAL ROUTE
Collect labelled pairs (x,y)
Compute prediction fθ(x)
Measure classification loss
Move the decision boundary
Return p(y|x) or label
JOINT / GENERATIVE ROUTE
Collect examples and conditions
Model p(x|y), p(y), or p(x|c)
Optimize likelihood or surrogate
Score or sample data
Optionally derive p(y|x)
07
VISUALIZATION

What information flows where?

Observed x → Discriminative model → Label / score y · Condition c → Generative model → Generated x

The same object can appear in different roles. A label y is an output for a classifier but can be a condition supplied to a class-conditional generator.

08
ARCHITECTURE

Highlight both roles in RAG

Question ↓ Intent classifier ↓ Retriever ↓ Relevance scorer ↓ Context ↓ Generator ↓ Claim verifier ↓ Answer

Classifiers and scorers control routing and evidence. The generator produces language. Oracle and other tools remain authoritative for exact structured values.

09
MATHEMATICS

Joint, conditional, and Bayes

Joint factorization:
p(x,y) = p(x|y)p(y) = p(y|x)p(x)
Bayes’ rule:
p(y|x) = p(x|y)p(y) / p(x)
Discriminative cross-entropy for one example:
L = − Σᵧ 1[y=y*] log pθ(y|x)

A generative classifier estimates the likelihood and prior, then normalizes across classes. A discriminative classifier optimizes the posterior or decision boundary directly.

10
WORKED EXAMPLE

Spam classification with Bayes

Suppose p(spam)=0.20. The word “offer” appears with likelihood p(offer|spam)=0.60 and p(offer|not spam)=0.10.

p(spam|offer) = (0.60×0.20) / [(0.60×0.20)+(0.10×0.80)] = 0.12/0.20 = 0.60

The generative classifier modelled how words appear under each class and derived a 60% posterior. A logistic classifier would instead learn the posterior or decision score directly.

12
CODE

From-scratch Gaussian view

PYTHON · CONCEPTUAL 
import math

def gaussian(x, mean, std):
    z = (x - mean) / std
    return math.exp(-0.5*z*z) / (std*math.sqrt(2*math.pi))

classes = {
    "relevant": {"prior": .4, "mean": .8, "std": .1},
    "irrelevant": {"prior": .6, "mean": .3, "std": .2},
}
score = .72
joint = {label: c["prior"]*gaussian(score,c["mean"],c["std"])
         for label,c in classes.items()}
posterior = {k:v/sum(joint.values()) for k,v in joint.items()}

The class-conditional Gaussian is generative; normalization yields a discriminative posterior.

19
RECALL

Knowledge check

Which distribution does logistic regression model?
It directly models a conditional class probability such as p(y|x).
Why is Naive Bayes generative?
It models priors and class-conditional feature likelihoods, defining a joint model.
Is a reranker generative?
Usually it is discriminative: it scores query-document relevance.
Is an LLM always used generatively?
No. It can be used for classification, scoring, extraction, or generation.

CAREER PRACTICE

Interview questions

Compare logistic regression and Naive Bayes.
Logistic regression directly models the posterior; Naive Bayes models priors and class-conditional likelihoods.
Can a discriminative component improve generation?
Yes. Rerankers, safety classifiers, routers, and verifiers can guide or evaluate generation.
When prefer a direct classifier?
For a stable, well-labelled prediction task where generation adds no value.
Where is this visible in RAG?
Routing and relevance scoring are commonly discriminative; answer synthesis is generative.
